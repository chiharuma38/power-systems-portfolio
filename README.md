# Power Systems Engineering Portfolio

Open-source power systems analysis tools built with Python and pandapower.

All projects use publicly available benchmark networks and real energy market data. No commercial software licenses required.

**Background:** Power systems engineer with PSS/E and Python automation experience from GE Vernova and Siemens. Starting the SENSE MSc at KTH Royal Institute of Technology, Stockholm, in August 2026.

## Setup

```bash
git clone https://github.com/chiharuma38/power-systems-portfolio.git
cd power-systems-portfolio
pip install -r requirements.txt
jupyter notebook
```

**Key packages:** pandapower 2.14.1, numpy 1.26.4, pandas 2.1.4
